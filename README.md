CodeAlpha Data Visualization Project

Overview

This project analyzes an illustrative student performance dataset and creates visualizations to explore subject scores, student averages, and attendance.

Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn

Dataset

The CSV dataset contains student names, daily study hours, attendance percentages, and scores in Mathematics, Science, and English. The data is illustrative and does not represent actual student records.

Visualizations

1. Average score comparison by subject
2. Average scores by student
3. Attendance percentage versus average score
4. Score distribution by subject

How to Run

1. Install Python.
2. Install dependencies with "python -m pip install -r requirements.txt".
3. Run "python main.py".

Output

Charts and the insights report are saved in the "outputs" folder.
